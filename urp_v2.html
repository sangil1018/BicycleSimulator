Unity 6.3 URP 극사실주의 그래픽 세팅 및 최적화 가이드

데스크톱 인터랙티브 · 실감형 설치 콘텐츠를 위한 하이엔드 렌더링 설정과 프레임 방어 지침
Unity 6.3 (6000.3) / URP 17.x 기준 · 메뉴 경로와 추천값 포함

필수 극사실 베이스라인에 반드시 필요 권장 시각·성능 대비 효과 큼 선택 상황·씬에 따라 선별 적용

1. 프로젝트 및 전역 그래픽 설정

그래픽의 기초 공사 단계입니다. 여기가 틀어져 있으면 뒤에서 아무리 조명을 다듬어도 사실감이 나오지 않습니다.

프로젝트 전역

필수Color Space = Linear▶
메뉴 경로
Edit > Project Settings > Player > Other Settings > Rendering
추천 설정
Color Space: Linear (Auto Graphics API 해제 후 DX12 우선 권장)

감마 공간에서는 빛의 감쇠와 혼합이 물리적으로 틀리게 계산됩니다. PBR의 대전제라 이것부터 확인하세요. 이미 진행 중인 프로젝트라면 변경 시 전체 룩이 바뀌므로 조명 재조정이 필요합니다.

필수Render Graph (Compatibility Mode 해제)6.3 기본 활성▶
메뉴 경로
Edit > Project Settings > Graphics > Pipeline Specific Settings > URP
추천 설정
Compatibility Mode (Render Graph Disabled): 해제 상태 유지

Unity 6.3부터 Compatibility Mode는 URP_COMPATIBILITY_MODE 컴파일 디파인 뒤로 숨겨져 사실상 Render Graph가 전제입니다. 구버전에서 올라온 프로젝트나 서드파티 Renderer Feature가 회색 화면을 내면 해당 에셋의 Render Graph 대응 버전을 확인하세요.

필수Default Render Pipeline 지정 확인▶
메뉴 경로
Edit > Project Settings > Graphics > Default Render Pipeline 품질 레벨별 override: Edit > Project Settings > Quality > Render Pipeline Asset
추천 설정
고품질 URP Asset 지정 / 설치물은 품질 레벨을 하나만 남겨두기

Quality 레벨에 URP Asset이 지정돼 있으면 그것이 우선하고, 비어 있으면 Graphics의 Default가 쓰입니다. 레벨을 하나만 남기면 현장에서 엉뚱한 품질로 실행되는 사고를 막을 수 있습니다.

URP Asset / Renderer

필수URP Asset — Quality (HDR · Render Scale · Upscaling)▶
메뉴 경로
URP Asset 선택 > Inspector > Quality
추천 설정
HDR: 켬 / HDR Precision: 64 Bit / Render Scale: 1.0 (부하 시 0.8~0.9) Upscaling Filter: Spatial-Temporal Post-Processing (STP) / Anti Aliasing(MSAA): Disabled

HDR은 Bloom·ACES 톤매핑의 전제조건입니다. 64 Bit Precision은 밝은 하이라이트의 계단 현상을 줄여줍니다. STP·TAA 같은 시간 누적 AA를 쓸 때 MSAA는 비용만 늘고 이점이 적으니 끄는 편이 낫습니다.

필수URP Asset — Lighting (Main/Additional Light · Probe)▶
메뉴 경로
URP Asset 선택 > Inspector > Lighting
추천 설정
Main Light: Per Pixel + Cast Shadows / Additional Lights: Per Pixel (Forward+에선 개수 제한 없음) Light Probe System: Probe Volumes (APV) / Reflection Probe Blending · Box Projection: 켬

Forward+에서는 Additional Lights의 개수 상한이 사라져 다중 광원이 자유롭습니다. Reflection Probe Blending을 켜야 프로브 경계에서 반사가 튀지 않습니다.

권장URP Asset — Shadows▶
메뉴 경로
URP Asset 선택 > Inspector > Shadows
추천 설정
Max Distance: 씬에 필요한 최소값 (실내 30~50m) / Cascade Count: 4 Shadow Resolution: 4096 / Soft Shadows: 켬, Quality: High / Depth Bias 1.0 · Normal Bias 1.0에서 미세 조정

Max Distance는 화질과 비용을 동시에 좌우하는 최대 변수입니다. 무작정 늘리지 말고 카메라가 실제로 닿는 범위로 조이세요. 그림자 끝단이 끊겨 보이면 Distance를, 표면에 줄무늬(섀도 아크네)가 생기면 Bias를 조정합니다.

필수Universal Renderer — Rendering Path = Forward+2022.2+▶
메뉴 경로
URP Asset > Renderer List에서 Renderer 더블클릭 > Inspector > Rendering
추천 설정
Rendering Path: Forward+ / Depth Priming Mode: Auto / Intermediate Texture: Auto

Forward+는 오브젝트당 조명 제한(4~8개)을 없애고, GPU Resident Drawer의 전제 조건이기도 합니다. Deferred+도 GPU Resident Drawer와 호환되지만 반투명·머티리얼 다양성에서 Forward+가 무난합니다.

필수Depth / Opaque Texture 버퍼링▶
메뉴 경로
URP Asset 선택 > Inspector > Rendering (Depth Texture / Opaque Texture)
추천 설정
Depth Texture: 켬 / Opaque Texture: 켬 (굴절·반투명 효과 필요 시) / Opaque Downsampling: None

SSAO·SSR·포그 등 화면 공간 효과가 깊이 버퍼를 요구합니다. Depth Texture가 꺼져 있으면 효과가 조용히 동작하지 않으니 먼저 확인하세요. SSAO의 Depth Normals 소스를 쓰면 노멀 프리패스가 추가로 필요합니다.

파이프라인 선택 참고 — 레이 트레이싱, 네이티브 볼류메트릭 포그, 물리 광량 단위(Lux/Lumen)까지 필요한 극한의 사실감이 목표라면 HDRP가 정공법입니다. URP는 이 문서의 기법들로 HDRP에 근접할 수 있지만 일부는 서드파티나 커스텀으로 메꿔야 합니다. 데스크톱 고정 사양 설치물이면서 위 기능이 핵심이라면 초기 단계에서 HDRP 전환을 한 번 저울질해 보세요.

2. 빛의 시뮬레이션: GI · 화면 공간 효과 · 공기감

공간 전체의 거시적인 빛(GI)과 미세한 디테일(SSAO·SSR), 그리고 공기감(포그)을 겹겹이 쌓아 현실감을 부여합니다.

전역 조명 (GI)

필수APV (Adaptive Probe Volumes)2022.2+▶
메뉴 경로
① Project Settings > Graphics > Pipeline Specific Settings > URP > Light Probe System = Probe Volumes ② GameObject > Light > Adaptive Probe Volume ③ Window > Rendering > Lighting > Adaptive Probe Volumes 탭 > Bake
추천 설정
Global 방식으로 씬 전체 감싸기 / Min Probe Spacing 0.5~1m, Max 8~16m Normal Bias 0.33 / 실내외 혼합 씬이면 Sky Occlusion 켬

간접광을 지오메트리 밀도에 맞춰 적응적으로 배치합니다. Probe Spacing을 너무 촘촘히 하면 베이크 시간과 메모리가 급증하니, 빛 변화가 큰 구역만 Probe Adjustment Volume으로 국소 보강하는 편이 효율적입니다.

권장베이크 GI (Progressive GPU Lightmapper)▶
메뉴 경로
Window > Rendering > Lighting > Scene 탭 > Lightmapping Settings 대상 오브젝트: Inspector 우상단 Static 드롭다운 > Contribute GI
추천 설정
Lightmapper: Progressive GPU / Lightmap Resolution: 20~40 texels per unit (히어로 오브젝트 60+) Max Lightmap Size: 2048~4096 / Direct Samples 64 · Indirect Samples 512 / Denoiser: Optix / Compress Lightmaps: 해제

정적 설치물이라면 실시간 GI보다 베이크가 화질·프레임 모두 압도적으로 유리합니다. Compress를 끄면 용량은 늘지만 그라데이션 밴딩이 사라집니다.

권장Mixed Lighting 모드▶
메뉴 경로
Window > Rendering > Lighting > Scene 탭 > Mixed Lighting 라이트별 모드: Light 컴포넌트 > Mode
추천 설정
Lighting Mode: Shadowmask / 배경 조명은 Light Mode를 Mixed, 인터랙션 반응광만 Realtime

Shadowmask는 정적 그림자를 텍스처로 굽고 동적 오브젝트만 실시간 그림자를 받게 해 실시간 그림자 개수를 크게 줄입니다. Baked Indirect는 그림자가 전부 실시간이라 더 무겁지만 동적 변화에 자연스럽습니다. 설치물은 Shadowmask 권장.

선택Area Light (베이크 전용)▶
메뉴 경로
GameObject > Light > Area Light → Inspector > Mode = Baked
추천 설정
Mode: Baked 고정 / 창문·간접 조명·소프트박스 연출에 사용 / 실시간 필요 시 Spot + 쿠키로 근사

URP에서 Area Light는 실시간으로 동작하지 않습니다(베이크에만 기여). 실시간처럼 켜두면 씬 뷰에서만 보이고 플레이 모드에서 사라져 혼란스러우니 Mode를 반드시 Baked로 두세요.

화면 공간 효과 (Renderer Feature)

필수SSAO (Screen Space Ambient Occlusion)▶
메뉴 경로
Renderer(Universal Renderer Data) 선택 > Inspector > Add Renderer Feature > Screen Space Ambient Occlusion
추천 설정
Method: Interleaved Gradient / Source: Depth Normals / Intensity 0.5~1.0 / Radius 0.25~0.5 Direct Lighting Strength 0.15~0.25 / Samples: Medium / Blur Quality: High

접촉면 그림자로 물체가 바닥에 "앉아 있는" 느낌을 만듭니다. Direct Lighting Strength를 높이면 직사광까지 어두워져 때가 낀 듯 인위적인 느낌이 나므로 낮게 유지하는 것이 사실감의 핵심입니다.

권장SSR (Screen Space Reflections)2023.2+▶
메뉴 경로
Renderer > Add Renderer Feature > Screen Space Reflections 세부값: Global Volume > Add Override > Screen Space Reflection
추천 설정
Resolution: Half (부하 큼) / Max Steps 32~64 / Thickness 0.05~0.1 젖은 바닥·유리·금속 등 Smoothness 높은 표면 위주로 사용

화면 밖 정보는 반사할 수 없어 화면 경계에서 반사가 사라집니다. Reflection Probe를 밑에 깔고 SSR을 그 위에 얹는 조합이 안정적입니다. 프레임이 부족하면 가장 먼저 Half Resolution 또는 해제를 검토할 항목입니다. 2023.2 미만에서는 내장되어 있지 않아 서드파티(SSRR 등)나 Planar Reflection으로 대체해야 합니다.

선택Decal Renderer Feature▶
메뉴 경로
Renderer > Add Renderer Feature > Decal
추천 설정
Technique: Automatic / 누수·얼룩·마모 표현으로 표면 반복감 제거

같은 텍스처가 반복되는 바닥·벽에 데칼로 불규칙성을 주면 사실감이 크게 올라갑니다. 극사실주의에서 가장 저렴하게 "실제로 쓰인 공간" 느낌을 내는 방법입니다.

공기감 (볼류메트릭)

권장볼류메트릭 포그 — URP 네이티브 미지원▶
메뉴 경로
(내장 없음) 서드파티 / 오픈소스 도입 필요
추천 설정
HAZE (Alisavakis) — RenderGraph froxel 방식, 라이트 쿠키·SSMS 지원, 아트 컨트롤 풍부 AERO (Mirza Beig) — 무료 레이마칭, Shader Graph 연동, 경량 (Unity 6.2+) Unity-URP-Volumetric-Light (오픈소스) — Render Graph · APV 호환, Forward+/Deferred+ 권장

URP는 Unity 6 기준으로도 볼류메트릭 포그가 내장되어 있지 않습니다. 실내 빛줄기(God Ray)는 극사실 분위기의 핵심이라 SSR처럼 외부 솔루션으로 메워야 합니다. 도입 시 반드시 Render Graph 대응 버전인지 확인하세요.

선택기본 Fog + Height Fog (경량 대안)▶
메뉴 경로
Window > Rendering > Lighting > Environment 탭 > Fog
추천 설정
Mode: Exponential Squared / Density 0.005~0.02 / 색은 하늘·주광원 색과 맞추기

볼류메트릭까지 갈 예산이 없을 때 원경 공기 원근만이라도 확보하는 방법입니다. 포그 색을 스카이박스와 어긋나게 두면 원경이 붕 떠 보이니 색 매칭이 중요합니다.

3. 머티리얼 & 텍스처 품질

극사실주의는 렌더 세팅보다 애셋 품질이 좌우하는 경우가 많습니다. 조명을 아무리 잘 깔아도 텍스처와 머티리얼 정합이 무너지면 CG 티가 납니다.

텍스처 메모리 / 품질

필수Texture Streaming (Mipmap Streaming)▶
메뉴 경로
Edit > Project Settings > Quality > Textures > Texture Streaming 텍스처별: 텍스처 선택 > Inspector > Streaming Mip Maps 체크
추천 설정
Texture Streaming: 켬 / Memory Budget: VRAM의 50~60% (12GB 카드 기준 4096~6144MB) Max Level Reduction: 2

4K 텍스처를 다수 쓰는 극사실 씬에서 VRAM 초과를 막는 안전장치입니다. Budget이 너무 낮으면 카메라 이동 시 텍스처가 흐릿하게 늦게 로드되는 팝핑이 보이니 현장 GPU 기준으로 여유 있게 잡으세요.

권장Anisotropic Filtering▶
메뉴 경로
Edit > Project Settings > Quality > Rendering > Anisotropic Textures
추천 설정
Anisotropic Textures: Forced On / 개별 텍스처는 Aniso Level 4~8 (바닥·벽 등 시선에 비스듬한 표면)

바닥처럼 시선과 각도가 큰 표면의 원경이 뭉개지는 것을 방지합니다. 비용 대비 체감 화질 개선이 커서 데스크톱 타깃이면 Forced On으로 두는 편이 편합니다.

선택텍스처 압축 포맷 (BC7 / BC5)▶
메뉴 경로
텍스처 선택 > Inspector(Import Settings) > 하단 Windows 플랫폼 탭 > Override 체크 > Format
추천 설정
Albedo · Mask: BC7 / Normal Map: BC5 (Texture Type을 Normal map으로 지정) Max Size 2048~4096 / sRGB는 컬러만 켜고 Mask · Roughness는 해제

노멀맵을 일반 컬러 압축(BC1)으로 두면 굴곡이 계단처럼 깨집니다. Metallic/Smoothness 같은 데이터 텍스처에 sRGB가 켜져 있으면 값이 왜곡되니 반드시 해제하세요. 여러 텍스처를 한 번에 선택하면 일괄 적용됩니다.

PBR 머티리얼 (Lit 셰이더)

필수Metallic / Smoothness 채널 정합▶
메뉴 경로
머티리얼 선택 > Inspector > Surface Inputs (Shader: Universal Render Pipeline/Lit)
추천 설정
Workflow Mode: Metallic / 금속 1.0 · 비금속 0.0 (중간값은 혼합 표면만) Smoothness Source: Metallic Alpha Smoothness 참고값 — 완전 매트 0.1~0.3 / 광택 목재 0.5~0.7 / 젖은 표면·유리 0.85+

알베도에 조명이나 AO가 이미 구워진 텍스처는 이중 음영을 만들어 CG 티의 주범이 됩니다. 금속은 알베도가 반사색을 담당하고 확산광이 거의 없다는 PBR 규칙을 지켜야 조명 반응이 자연스럽습니다.

권장Normal Map 강도▶
메뉴 경로
머티리얼 > Inspector > Surface Inputs > Normal Map (맵 할당 시 우측에 강도 필드 표시)
추천 설정
Strength 0.8~1.0 유지 (1.5 이상은 실루엣과 어긋나 가짜 티) / 큰 요철은 지오메트리, 미세 굴곡만 노멀

노멀맵을 과하게 올리면 그림자 방향과 실제 실루엣이 충돌해 오히려 평평해 보입니다. 강도를 올리고 싶어지면 대개 텍스처 자체나 지오메트리 문제입니다.

권장Detail Map (근접 디테일)▶
메뉴 경로
머티리얼 > Inspector > Detail Inputs (Mask · Detail Albedo x2 · Detail Normal Map)
추천 설정
Detail Albedo / Normal 할당 후 Tiling을 메인의 8~20배 / Detail Normal Scale 0.5~1.0 관람객이 가까이 붙는 바닥·벽·손잡이에 우선 적용

인터랙티브 설치물은 관람객이 표면에 얼굴을 들이대는 상황이 실제로 발생합니다. 메인 텍스처 해상도를 올리는 것보다 디테일 맵을 겹치는 편이 메모리 대비 효율이 훨씬 좋습니다.

선택Parallax Occlusion (Height Map)▶
메뉴 경로
머티리얼 > Inspector > Surface Inputs > Height Map
추천 설정
Height Scale 0.02~0.08 (과하면 가장자리 왜곡) / 벽돌·자갈·타일 등 깊이감이 중요한 표면만 선별 적용

픽셀 셰이더 부하가 있으니 카메라가 가까이 가는 핵심 표면에만 쓰세요. 값을 크게 올리면 실루엣 경계에서 텍스처가 미끄러지듯 흘러내리는 현상이 보입니다. 시선을 비스듬히 두고 확인하는 것이 검증 요령입니다.

4. 영화적 마감 및 포스트 프로세싱

디지털 렌더링 특유의 날것 느낌을 제거하고 영화 카메라 렌즈의 특성을 부여합니다. 대부분 Global Volume의 Override로 추가합니다.

Global Volume이 없다면 — GameObject > Volume > Global Volume으로 생성한 뒤, Inspector의 Profile 옆 New 버튼으로 프로파일을 만들고 Add Override로 아래 항목들을 추가합니다.

5. 안정적인 프레임 방어를 위한 최적화

인터랙티브 환경에서 실시간 렌더링 부하와 외부 데이터 처리(OpenCV·뎁스 카메라 등)가 충돌할 때 해결하는 방법론입니다.

A. CPU 바운드 — 드로우콜 & 컬링

권장GPU Resident Drawer (3단계 설정)Unity 6▶
메뉴 경로
① Project Settings > Graphics > Shader Stripping > BatchRendererGroup Variants = Keep All ② URP Asset > Inspector > Rendering > SRP Batcher 켬 → GPU Resident Drawer = Instanced Drawing ③ Renderer List에서 Renderer 더블클릭 > Rendering Path = Forward+ (또는 Deferred+)

D. 설치물 운영 세팅

현장 사고 방지 — 아래 두 항목은 무인 운영 설치물에서 가장 흔한 장애 원인입니다. 빌드 전 반드시 확인하세요.
① Run In Background가 꺼져 있으면 포커스를 잃는 순간 콘텐츠가 정지합니다.
② 멀티 디스플레이는 Display.displays[i].Activate()를 호출하지 않으면 2번째 이후 화면이 검게 남습니다.
권장Target Frame Rate / VSync▶
메뉴 경로

추천 설정

전시장 디스플레이는 대부분 60Hz 고정입니다. 프레임을 그 이상 뽑아봐야 티어링과 발열만 늘어납니다. 프레임 상한을 걸어 GPU 여유를 남겨두면 인터랙션 순간의 스파이크를 흡수할 수 있습니다.

무인 운영 설치물은 Run In Background가 꺼져 있으면 포커스를 잃는 순간 멈춥니다. 다면 프로젝션이면 Exclusive Fullscreen이 오히려 방해가 되므로 Fullscreen Window를 씁니다.
