로그

* Chrome/Edge에서 파일을 직접 열어 사용합니다 (Web Serial). 최초 1회만 연결 버튼으로 포트를 선택하면, 다음부터는 페이지를 열자마자 자동 연결됩니다 (브라우저 보안상 첫 허용은 수동 필수).
* ESP32는 10초 주기로 H keep-alive를 자동 송신하며, 5초 무수신 시 상태 줄이 붉게 바뀝니다. 케이블을 다시 꽂으면 자동 재연결됩니다.
* Unity가 같은 포트를 점유 중이면 열리지 않습니다 — 게임을 끄고 테스트하세요.
* PAS 진단 — 페달을 돌리면서 상태 줄의 PAS펄스와 lv를 보세요. 펄스가 늘면 정상입니다. lv는 0/1로 바뀌는데 펄스가 안 늘면 PAS 인터럽트가 죽은 것이고, R — PAS 재초기화 버튼으로 복구됩니다(Unity는 레벨 진입 시와 감지 시 자동 전송). 반대로 lv가 고정이면 신호선이 죽은 것이라 센서 전원/배선 문제이며 R로는 고쳐지지 않습니다.
* 워치독(v6.2): loop가 5초간 굳으면 보드가 자동 리셋됩니다. 부팅 로그의 reset_reason이 반복해서 TASK_WDT로 찍히면 loop가 멈추고 있다는 뜻이니 I2C 락업을 의심하세요 (정상은 POWERON).
